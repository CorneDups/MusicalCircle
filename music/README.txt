MUSIC FOLDER GUIDE
==================

Create one folder per album or collection and place MP3 files inside it.
Each folder containing MP3 files becomes an option in the website dropdown.

Optional album files:
- album.json       Album title, artist, colors, visualizer and track settings
- cover.jpg        Centre album artwork
- background.jpg   Full-page album background

Song-specific artwork can use the same base filename as the MP3:
- 02 - River.mp3
- 02 - River.jpg

It can also be placed inside an artwork subfolder:
- artwork/02 - River.png

The player first tries embedded MP3 artwork, then song artwork, then cover.jpg.
See the main README.md for the complete album.json format.
